# 最终实验结果

系统首先从完整、可执行的 gap generator 程序中进行自监督发现，再在不改变已证明几何尾部的条件下微调最小八个 gaps。最终冻结的实用序列开头为：

```text
1, 3, 8, 20, 47, 116, 300, 585, 1416, 3303, ...
```

有限前缀搜索共运行24轮，评测311个候选。独立 Validation 使用 seed 400 冻结唯一候选；一次性 Test 使用未参与搜索和选择的 seed 1999。全部任务均无截断。

在 \(10^7<N\le10^8\) 的25个等权任务上，最终候选相对三条最强实用基线的平均总操作数变化为：

| 基线 | 最终候选的变化 |
|---|---:|
| Sedgewick | -1.793% |
| Tokuda | -0.079% |
| Ciura | -0.086% |

因此预注册成功规则通过。扩展比较还包括 Shell、Hibbard、Knuth 和 Pratt；最终候选在七条经典基线中取得最低的等任务几何平均总操作数。这里的主评价对象是完全随机选择的任务总体，因此分布拆分用于解释收益来源，不要求每个分布逐项全胜。

机器可读结果：

- `result/final/selected.json`：最终序列定义；
- `result/final/validation.json`：独立验证；
- `result/final/test.json`：封闭测试；
- `result/final/benchmark.json`：七条经典基线的逐任务比较；
- `result/final/experiment.md`：完整实验归档。
