# compound/carry 推导附录

本文只保存理论主线所需的精确推导。项目结论、核心命题和研究门槛统一见 [冻结候选的理论主线](候选序列时间复杂度证明.md)。

## 1. 记号

冻结序列为：

```text
h_t=floor(alpha(A/B)^t)，
gcd(A,B)=1， A>B>1。
```

固定：

```text
d=h_t，
a_i=h_(t+i)， 1<=i<=m。
```

乘子半群为：

```text
M_t(m)={k>=0 : kd in <a_1,...,a_m>}。
```

## 2. 连续区间引理

若加法半群 `M` 包含：

```text
K,K+1,...,2K-1，
```

则包含所有 `n>=K`。

证明：区间是归纳起点。对 `n>=2K`，有 `K in M` 且 `n-K>=K`；按强归纳 `n-K in M`，所以 `n in M`。

因此：

```text
conductor(M)<=K，
genus(M)<=K-1。
```

## 3. 二维清分母恒等式

定义：

```text
E_i=B^i a_i-A^i d，
q_i=A^iB^(m-i)，
v_i=B^(m-i)E_i。
```

由于 `a_i` 和 `d` 来自同一有理几何取整轨道：

```text
-B^i<E_i<A^i，
abs(v_i)<q_i。
```

从：

```text
B^i a_i=A^i d+E_i
```

乘以 `B^(m-i)` 并求和，得到：

```text
B^m sum c_i a_i
= d sum c_i q_i+sum c_i v_i。
```

因此以下两者等价：

```text
kd=sum c_i a_i， c_i>=0，
```

以及存在整数 `D` 满足：

```text
sum c_i q_i=kB^m-D，
sum c_i v_i=Dd。                           (C)
```

该变换可双向恢复，所以不是松弛或近似。

### 3.1 非零 D 的必要尺度

若 `D!=0`，则：

```text
abs(D)d
<=sum c_i abs(v_i)
<sum c_i q_i
=kB^m-D。
```

因为非零整数 `D` 至少有绝对值 1，所以：

```text
k=Omega(d/B^m)。
```

这说明 `d/B^m` 是允许有界非零进位的自然尺度。更小的 `d/A^m` 尺度会渐近地强迫 `D=0`，不是匹配目标指数所必需的要求。

## 4. q 坐标的 compound 正规形

所有 `q_i` 都含因子 A。令：

```text
w_i=q_i/A=A^(i-1)B^(m-i)。
```

生成元为：

```text
B^(m-1), AB^(m-2), ..., A^(m-1)，
```

并满足：

```text
A w_i=B w_(i+1)。
```

每个可表示整数 N 有唯一正规形：

```text
N=sum c_i^(0)w_i，
0<=c_i^(0)<B for i>=2。
```

从最高下标开始模 B 逆向确定 digit，最后剩余量决定 `c_1^(0)`。当且仅当 `c_1^(0)>=0` 时，N 属于该半群。

对应 Apéry 集为：

```text
Ap
={sum from i=2 to m of c_i w_i : 0<=c_i<B}。
```

所以 Frobenius 数精确为：

```text
F_W
=(B-1)sum from i=2 to m of w_i-w_1
=O(A^m)。
```

对给定 `k,D`，q 坐标要求：

```text
N=(kB^m-D)/A。
```

选取 `D` 为 `kB^m mod A` 的有界代表后，只要 k 前的常数足够大，`N>F_W`，q 坐标就有非负正规表示。这里的常数可依赖固定的 A、B；这不影响多项式幂，但可能极大。

## 5. q 核的完整 carry 基

定义：

```text
r_i=A unit_i-B unit_(i+1)， 1<=i<m。
```

因为：

```text
Aq_i-Bq_(i+1)=0，
```

每个 `r_i` 都在 q 核中。利用 A、B 互素并逐项取模，可得它们生成完整整数核。

所以所有相同 q 坐标的整数表示唯一写成：

```text
c=c^(0)+sum z_i r_i。
```

非负性等价于：

```text
c_1^(0)+Az_1>=0，

c_i^(0)-Bz_(i-1)+Az_i>=0， 1<i<m，

c_m^(0)-Bz_(m-1)>=0。                     (N)
```

## 6. v 坐标化为有界误差方程

定义局部误差：

```text
e_(t+i)=B h_(t+i+1)-A h_(t+i)，
-B<e_(t+i)<A。
```

有递推：

```text
E_(i+1)=AE_i+B^i e_(t+i)。
```

因此一个相邻 carry 对 v 坐标的作用为：

```text
Av_i-Bv_(i+1)=-B^m e_(t+i)。
```

将正规形和 carry 代入 (C)，剩余方程严格化为：

```text
sum z_i e_(t+i)
=(sum c_i^(0)v_i-Dd)/B^m。                 (R)
```

右侧自动是整数。原正表示问题至此等价于同时解 (R) 和 (N)。

这就是项目当前唯一未解决的构造环节。

## 7. 为什么不能证明任意 rounding state

通用命题是假的。下面给出一个精确参数族，而不是有限样例。

固定 `A/B=5/2`。对每个 `L>=2` 选择：

```text
u_L=3 mod 4，
6(5/2)^L<=u_L<6(5/2)^L+4，
d_L=2^L u_L，
m=L+2。
```

此时 `m=ceil(log_5 d_L)`。最后两个 future gaps 记为 `b_L,c_L`，则：

```text
b_L=(5^(L+1)u_L-1)/2，
c_L=(5^(L+2)u_L-3)/4，

local errors=0^(L-1),-1,1，
2c_L-5b_L=1。
```

所以 future gaps 的 gcd 为 1，quotient 有限。

假设 `k d_L` 有非负表示，最后两个生成元的系数为 `y,z`。前 L 个生成元都被 `u_L` 整除，模 `u_L` 得：

```text
2y+3z=0 mod u_L。
```

若 `y=z=0`，则早期生成元强迫 `5 divides k`。否则：

```text
y+z>=u_L/3，
k>=u_L b_L/(3d_L)。
```

所以该阈值以下的非 5 倍数都是 quotient 空洞，从而：

```text
conductor(M_L)=Omega((5/2)^(2L))，
d_L/2^m=Theta((5/2)^L)，

conductor(M_L)/(d_L/2^m)
=Omega((5/2)^L)。
```

因此统一覆盖任意 rounding state 的 `poly(m)d/B^m` conductor 上界不存在。冻结 V3 必须使用自身精确轨道的额外性质。

## 8. 核心条件与复杂度换算

冻结 V3 需要证明：存在固定 C 和多项式 P，使充分大 t 上，取：

```text
d=h_t，
m=ceil(log_A d)，
K=ceil(CP(m)(d/B^m+1))，
```

都有：

```text
[K,2K-1] subset M_t(m)。
```

记：

```text
r=log_A(A/B)。
```

则：

```text
d/B^m=Theta(d^r)，
r=0.024901468995116044855...。
```

区间引理给出：

```text
U_t(m)=O(d^r polylog(d))。
```

有完整窗口的 pass 求和指数为：

```text
(2r+1)/(r+1)。
```

没有完整窗口的顶部 pass 使用 `N^2/d`，指数为：

```text
2-1/(1+r)。
```

二者相等：

```text
1+r/(1+r)
=1.02429645165747606869...。
```

这是严格的条件推论，不是当前已完成上界。
