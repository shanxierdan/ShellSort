# 冻结候选的理论主线

> **归档说明。** 本文记录的是单位伴随补全出现以前、针对纯几何序列直接进攻的历史路线，其中“尚未证明”等状态不再代表项目最终结论。最终完整证明、固定保护阈值和零密度增强上界统一见 [proof.md](proof.md)。

本文是项目理论部分的唯一主入口。它只回答四件事：研究对象是什么、已经证明了什么、核心命题是什么、什么结果才算下一步进展。

## 1. 研究对象

V3 冻结得到的符号序列定义为：

```text
h_t = floor(alpha (A/B)^t)，

alpha = 420574650882923 / 7668945023518835，
A     = 582942583375009，
B     = 250000000000000，
gcd(A,B)=1。
```

对规模 `N`，Shellsort 使用全部满足 `1<=h_t<N` 的不同正 gap，并按降序执行。

当前主线不是证明神经网络有用，也不是继续调搜索模型。主线是：

> 对这个已经冻结的无限整数序列，证明一个非平凡的最坏时间上界；或者严格证明当前候选不具备所需数论性质。

## 2. 当前状态

| 层次 | 当前结论 | 性质 |
|---|---|---|
| 有限实验 | seed 4 候选在 Validation 和 Extrapolation 都超过三条强基线 | 已完成的有限事实 |
| 序列结构 | 候选是精确的有理几何取整序列，gap 数为 `Theta(log N)` | 已证明 |
| 外部下界 | 代入 Zang 2026 arXiv v1 的有理几何序列定理得到 `Omega(N^1.024296...)` | 预印本条件下成立 |
| 我们的无条件上界 | `O(N^2)` | 已证明但平凡 |
| 目标上界 | `O(N^1.024296... polylog(N))` | 尚未证明 |

因此当前不能声称候选已经在渐近复杂度上超过 Ciura、Tokuda 或 Sedgewick。有限操作数优势与渐近定理是两类结论。

### 2.1 实验 baseline 的理论位置

下表比较仓库实际实现的 baseline。这里的“理论最强”只按已证明的最坏上界判断，不按有限实验速度判断。

| Baseline | 仓库中的形式 | 已证明的最坏上界 | gap 数量 | 理论位置 |
|---|---|---:|---:|---|
| Pratt | 所有 `2^p3^q<N` | `O(N log^2 N)` | `Theta(log^2 N)` | 全部 baseline 中最强 |
| Sedgewick | 两条 Sedgewick 公式的合并 | `O(N^(4/3))` | `Theta(log N)` | 稀疏实用 baseline 中最强 |
| Hibbard | `2^k-1` | `Theta(N^(3/2))` | `Theta(log N)` | 弱于 Sedgewick |
| Knuth | `(3^k-1)/2` | `Theta(N^(3/2))` | `Theta(log N)` | 弱于 Sedgewick |
| Shell | 反复减半 | `Theta(N^2)` | `Theta(log N)` | 经典最弱基线 |
| Tokuda | 取整的 `9/4` 几何序列 | 当前记录为 `O(N^2)`；Zang arXiv v1 给出 `Omega(N^1.2695...)` | `Theta(log N)` | 实验强，但缺少匹配非平凡上界 |
| Ciura-extension | Ciura 前缀后按 `2.25` 延伸 | 当前记录为 `O(N^2)` | `Theta(log N)` | 实验强，但缺少适用的非平凡上界 |

因此需要区分两个答案：

```text
全部实验 baseline：Pratt 的已证明渐近上界最强；

冻结选择使用的三条强基线
Sedgewick、Tokuda、Ciura-extension：
Sedgewick 的已证明渐近上界最强。
```

Pratt 在有限实验中不属于强基线，是因为 `Theta(log^2 N)` 个 passes 带来很大的实际常数和操作量，而不是因为其理论上界弱。

若我们的核心命题成立，目标上界：

```text
O(N^1.024296... polylog(N))
```

会严格强于 Sedgewick 的 `O(N^(4/3))` 保证，但仍弱于 Pratt 的 `O(N log^2 N)`。此外，比较两个上界只能比较“已知保证”，不能单独证明两个算法真实运行时间的渐近次序；严格胜负通常还需要另一方的下界。

## 3. Shellsort 真正需要控制的量

固定一个当前 gap：

```text
d = h_t。
```

取接下来已经执行过的 `m` 个更大 gap：

```text
a_i = h_(t+i)， 1<=i<=m。
```

定义乘子半群：

```text
M_t(m)
= {k>=0 : k d 可以由 a_1,...,a_m 非负整数表示}。
```

定义广义空洞数：

```text
U_t(m)
= 不属于 M_t(m) 的正整数 k 的数量。
```

若 future gaps 的总 gcd 不整除 `d`，则 `U_t(m)` 为无穷；否则 `M_t(m)` 是数值半群，`U_t(m)` 就是它的 genus。

Incerpi–Sedgewick 的 pass 引理给出：

```text
cost_t
<= O(min(N^2/d, N(U_t(m)+1)))。
```

所以核心不是估计单个普通 Frobenius 最大值，而是上界乘子半群的空洞数量。

## 4. 已经取得的正向数学进展

### 4.1 固定窗口不够

对任意固定 `m`，令：

```text
K_t = floor((h_t-1)/A^m)。
```

所有 `1<=k<=K_t` 且 `A` 不整除 `k` 的乘子都是空洞。因此：

```text
U_t(m)
>= K_t-floor(K_t/A)
= Omega(h_t)。
```

这是一条严格的必要性定理：要得到次线性的 `U_t`，窗口必须随 `h_t` 至少按对数增长。它结束了所有“固定 4、8、12 或 14 个 future gaps 即可证明低幂上界”的设想。

### 4.2 连续区间足以控制全部空洞

如果 `M_t(m)` 包含：

```text
K,K+1,...,2K-1，
```

那么由加法封闭性可归纳得到所有 `k>=K` 都属于 `M_t(m)`。所以：

```text
conductor(M_t(m)) <= K，
U_t(m) <= K-1。
```

这避免了只找两个互素生成元所产生的平方损失。

### 4.3 正表示已经精确归约为 compound/carry 问题

定义：

```text
E_i = B^i a_i-A^i d，
q_i = A^i B^(m-i)，
v_i = B^(m-i)E_i。
```

则：

```text
k d = sum c_i a_i， c_i>=0
```

当且仅当存在整数 `D` 使：

```text
sum c_i q_i = kB^m-D，
sum c_i v_i = Dd。                         (C)
```

其中 q 坐标除以公共因子 A 后是 compound 序列：

```text
B^(m-1), AB^(m-2), ..., A^(m-1)。
```

它有显式正规形，Frobenius 数也可精确计算。相同 q 坐标的全部整数表示由相邻 carry 生成：

```text
r_i = A unit_i-B unit_(i+1)。
```

再定义有界局部误差：

```text
e_(t+i)=B h_(t+i+1)-A h_(t+i)，
-B<e_(t+i)<A。
```

一个相邻 carry 对 v 坐标的作用严格等于：

```text
-B^m e_(t+i)。
```

所以 q 坐标已经解决，剩余困难是：在保持所有最终系数非负的同时，用 carry 解出一个有界整数误差方程。

这一步是真正的降维，但不是最终定理。

## 5. 唯一核心命题

令：

```text
d = h_t，
m = ceil(log_A d)。
```

需要证明存在只依赖冻结常数的 `C` 和一个固定多项式 `P`，使所有充分大的 `t` 都满足：

```text
K = ceil(C P(m)(d/B^m+1))，
[K,2K-1] subset M_t(m)。                    (Core)
```

等价地，需要对区间内每个 `k` 构造满足 (C) 的非负系数；在 carry 坐标中，就是统一解决：

```text
sum z_i e_(t+i) = target(k,D)，
```

同时满足链式非负容量约束。

核心不只是证明误差 gcd 为 1。完整证明必须同时控制：

1. residue/gcd 多快恢复；
2. 有效误差在窗口中的位置；
3. 解目标所需的 carry 大小；
4. 每一层正规形提供的非负容量。

## 6. 为什么这个尺度值得证明

记：

```text
r = log_A(A/B)
  = 0.024901468995116044855...。
```

在 `m=ceil(log_A d)` 时：

```text
d/B^m = Theta(d^r)。
```

若 (Core) 成立，则：

```text
U_t(m)=O(d^r polylog(d))。
```

有完整窗口的 passes 和顶部窗口不足的 passes 分别给出：

```text
beta_inside = (2r+1)/(r+1)，
beta_top    = 2-1/(1+r)。
```

两者相等：

```text
beta
= 1+r/(1+r)
= 1.02429645165747606869...。
```

因此 (Core) 会推出条件上界：

```text
T_worst(N)
= O(N^1.0242964517... polylog(N))。
```

该幂与 Zang 2026 arXiv v1 对本类有理几何 gap 给出的下界幂一致。这里必须保留两个限定：上界依赖尚未证明的 (Core)，下界来源是尚未同行评审的预印本。

## 7. 有限证据只放在证据层

以下结果可复算，但不进入定理前提：

- 77 条已有 quotient 证书通过精确二维恒等式和 carry 分解；
- 小模型 `A/B=5/2,d=131` 的 `223...445` 连续区间被直接构造；
- 冻结序列前 5000 项中，已解析起点的 error gcd 恢复长度最大 14；
- 同一前缀中正负误差同时出现的恢复长度最大 29。

这些结果验证实现、帮助提出引理，但不证明所有充分大的 `t`。

## 8. 已停止的路线

只保留结论，不再展开为主叙事：

- 固定 future-window：被 `U_t(m)=Omega(h_t)` 严格排除；
- 普通 Frobenius 最大值：不是 pass 真正需要的量；
- 两个互素 quotient 证书：合法但有平方损失，只作后备；
- 任意 rounding state 的通用可控性：存在指数坏前缀参数族，不能代替冻结轨道定理；
- 5000 项统计、随机性直觉和模型拟合：不能替代渐近量词。

详细代数推导见 [compound/carry 推导附录](最终上界攻击.md)。历史路线文件只保留摘要和链接。

## 9. 什么才算下一步进展

今后只有以下结果之一可以称为理论进展：

1. 证明 (Core)，或证明一个仍能给出 `kappa<1/2` 的较弱统一 genus 上界；
2. 构造冻结 V3 精确轨道上的坏子序列，从而否定 (Core)；
3. 证明冻结误差词的定量逃逸定理，并给出足够的非负 carry 容量界。

增加有限样本、换坐标重写同一恒等式、或只在其他小有理基上成功，不再计作核心进展。
