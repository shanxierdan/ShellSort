# 固定窗口结论：归档摘要

本文件只保留已经证明、仍影响主线的结论。统一入口见 [冻结候选的理论主线](候选序列时间复杂度证明.md)。

对任意固定 `m`，令：

```text
K_t=floor((h_t-1)/A^m)。
```

清除有理递推分母后可证明：所有满足：

```text
1<=k<=K_t，
A does not divide k
```

的 `k h_t` 都不能由 `h_(t+1),...,h_(t+m)` 非负表示。因此：

```text
U_t(m)
>=K_t-floor(K_t/A)
=Omega(h_t)。
```

所以固定窗口不能产生次线性广义空洞上界。该结论只排除一种上界证明路线，不是 Shellsort 自身的 `Omega(N^(4/3))` 下界。

后续不再增加固定窗口实验；研究资源统一转向可变窗口与冻结 carry 可控性。
