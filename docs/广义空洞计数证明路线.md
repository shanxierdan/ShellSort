# 广义空洞计数：归档摘要

广义空洞是最终证明中的正确 pass 量，但本文件是单位伴随补全出现以前的归档，不再维护独立路线。最终闭合结果见 [proof.md](proof.md)。

保留的严格事实：

```text
M_t(m)={k>=0 : k h_t 可由 future gaps 非负表示}，
U_t(m)=正整数乘子中的不可表示数量。
```

Incerpi–Sedgewick 引理给出：

```text
cost_t<=O(min(N^2/h_t, N(U_t(m)+1)))。
```

固定 `m` 时已经证明 `U_t(m)=Omega(h_t)`，因此必须令窗口随尺度增长。当前选择：

```text
m=ceil(log_A h_t)。
```

若能证明从：

```text
K=O(poly(m)h_t/B^m)
```

开始有 K 个连续乘子属于 `M_t(m)`，就能得到目标 genus 上界。这个连续区间命题尚未证明，其 compound/carry 等价形式见 [推导附录](最终上界攻击.md)。
